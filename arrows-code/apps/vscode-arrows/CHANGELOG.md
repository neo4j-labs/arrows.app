# Changelog

## 0.1.0

First release.

- Canvas editor for `.arrows` files (the arrows.app engine, embedded)
- Two-way sync between the canvas and the JSON file
- Five layout algorithms: force, hierarchical, radial, circular, grid
- Cypher export
- SVG export
- Structural validator in the Problems panel
- Project-wide rename for labels and relationship types
- Six bundled examples
- Files round-trip with arrows.app
